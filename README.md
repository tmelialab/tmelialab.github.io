# Melia Lab — Research Website

Official research showcase of **Melia Lab**, focusing on bioinformatics software, computational genomics, and high-performance computing.

## Publish with GitHub Pages

1. Upload `index.html` and the `assets/` folder to the root of the `tmelialab.github.io` repository.
2. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)` and save.
3. Visit https://tmelialab.github.io once deployment finishes.

## Edit

- `index.html`: all website content and styles.
- `assets/melia-lab-logo.webp`: official Melia Lab logo.

Some project descriptions highlight ongoing research. Check publication status, statistics, and contact/recruitment details before publicizing opportunities. Replace GitHub-profile fallback links with project-specific repositories as they become available.
